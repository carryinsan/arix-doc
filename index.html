JavaScript integration

Import the local processing module from your ArixDoc deployment. The optional key preflight meters a hosted authorization request; OCR still runs on the user's device.

import { processDocument } from 'https://YOUR-ARIXDOC-DOMAIN/src/engine.js'; const result = await processDocument(file, { lang: 'eng', engine: 'auto', apiKey: 'YOUR_PUBLISHABLE_KEY', apiBase: 'https://YOUR-ARIXDOC-DOMAIN' }); console.log(result.pages, result.text);
Quota boundary: the server can enforce authorization requests made through the official SDK. Since OCR is local and the client controls its own JavaScript, a developer can fork the client and skip the preflight. No browser-only design can cryptographically prevent that. Never treat a publishable key as a secret or as authorization for access to sensitive server data.
